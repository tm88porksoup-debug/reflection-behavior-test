# 失敗したときの自分 — 反応と行動の自己理解チェック

失敗・過失・嘘・ルール違反・人を傷つけた行動をしてしまったとき、あるいはそれが発覚したときに、
自分の中でどんな反応が出やすいのかを60問で整理する自己理解ツール。

性格の良し悪しを判定するものではなく、「追い詰められたとき、自分はどこで判断を間違えやすいのか」
「どこなら踏みとどまれるのか」の見取り図を作るためのもの。

## 使い方

`index.html` はビルド不要の単体HTML。ブラウザで開けばそのまま動く。

- ローカル: ファイルをダブルクリック
- 配布: このファイル1つを渡す、または任意の静的ホスティングに置く
- GitHub Pages: Settings → Pages でこのブランチを公開すると `index.html` がそのまま配信される

## 構成

全60問／12問 × 5チャプター／目安12〜15分。

| セクション | 問数 | 形式 | 内容 |
|---|---|---|---|
| SECTION 1 | 36問 | 4択（SJT） | 「もし実際に起きたら」の場面選択 |
| SECTION 2 | 16問 | 6段階 | 「普段の自分」の自己評価（逆転項目あり） |
| SECTION 3 | 8問 | 2択×2 | 「適切だと思う対応」と「実際に取りそうな対応」 |

### 8軸

向き合うための反応（高いほどその行動が出やすい）

- **A 真実開示** — 自分に不利でも、事実を隠さず小出しにせず伝えられるか
- **B 責任受容** — 状況や他人の要因と切り分けて、自分が選んだ部分を認められるか
- **C 相手への影響理解** — 自分の意図ではなく、相手に実際に起きた損害や感情を見られるか
- **D 修復行動** — 謝罪で終わらず、戻す・直す・説明する行動まで進めるか
- **E 再発防止** — 感情的な反省で終えず、やり方や仕組みを実際に変えるか

問題を悪化させやすい反応（良し悪しではなく「出やすさ」）

- **F 自己正当化** / **G 防衛的反発** / **H 回避・隠蔽**

内部指標として **S（自己否定の出やすさ）** を持つが、8軸には含めずタイプ判定と文章生成にのみ使う。

### 主な出力

- **初動 → 立て直し** の2段階を11キャラクターで可視化
- **あなたの中にある矛盾** — 2軸の組み合わせから合成（該当がなければスコア差から自動生成）
- **危険トリガー** — 12条件のうち、本人のベースラインより有意に悪化した場面のみ提示
- **理解―実行ギャップ** — 適切さランク差と8軸上の距離を半々で合成
- **HOT / COLD 比較** — 同一の心理テーマで「失うものの大きさ」だけが違う11組のペア設問で比較
- **IF → THEN の5ルール** — スコアの組み合わせから生成される個別ルール
- 付随ツール: やらかしシミュレーター / 言い訳翻訳機 / 出来事整理 / 緊急モード / 未来の自分へのメモ / 共有用カード

## プライバシー

- 外部通信は一切なし（fetch / XHR / 外部スクリプト・フォント・画像すべてゼロ）
- 回答・履歴・メモは `localStorage` にこの端末のブラウザ内だけで保存される
- 結果の共有はスクリーンショットによる手動のみ
- 画面内のボタンからいつでも全削除できる

`<meta name="robots" content="noindex">` を付けているため、公開ホスティングに置いても検索エンジンには載らない。

## 注意

心理学研究の知見を参考にした自己理解ツールであり、臨床心理検査・医学的診断・
科学的に妥当性が検証済みの心理尺度ではない。将来の行動を予測するものでもない。
