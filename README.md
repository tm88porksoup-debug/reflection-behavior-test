# re:act note

**そのときの自分を知る。**

間違えたとき。責められたとき。失うのが怖くなったとき。
人は、いつも同じ自分ではいられません。

re:act note は「追い詰められたときに、自分の中でどんな反応が出やすいか」を知るための自己理解ツールです。
性格の良し悪しを判定したり、本性を暴くための診断ではありません。

<br>

## 使い方

`index.html` をブラウザで開くだけです。サーバー・ログイン・インターネット接続は不要です。

公開する場合は、このリポジトリを GitHub Pages（Settings → Pages → Branch: `main` / root）で公開してください。
サブディレクトリ公開（`https://ユーザー名.github.io/リポジトリ名/`）でも動くよう、すべて相対パスにしてあります。

### ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（診断・分析・全機能） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・表示方法 |
| `sw.js` | オフラインで開けるようにするService Worker |
| `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` | アプリアイコン |
| `apple-touch-icon.png` | iPhoneのホーム画面用アイコン |
| `og.png` | SNSにURLを貼ったときのプレビュー画像 |

### 公開設定

OGP（SNSに貼ったときのプレビュー）は絶対URLで指定してあります。現在の公開先は次のとおりです。

```
https://tm88porksoup-debug.github.io/reflection-behavior-test/
```

GitHub Pages を有効にするには、Settings → Pages → Branch: `main` / root を選びます。
公開先を変えるときは、`index.html` の `<head>` にある `og:url` / `og:image` / `twitter:image` の3か所を書き換えてください。

アプリを更新したときは、`sw.js` の `CACHE` の名前（`react-note-v1` の番号）を上げてください。
上げないと、古いキャッシュが残り続けることがあります。

## できること

| 機能 | 内容 |
|---|---|
| **re:act note** | そのときの自分を知る（60問の本診断） |
| **今日の1問** | 1日ひとつの短い問い。点数はつかず、診断結果にも影響しません |
| **re:play** | あの場面をもう一度考える（分岐する反応シミュレーター） |
| **re:phrase** | 言葉を整理する（防衛的な言葉を、責任を回避しない言い換えへ） |
| **re:mind** | 今の気持ちを確認する（焦り・怒り・怖さなどの確認と、1ステップずつの手順） |
| **re:view** | 相手からはどう見える？（自分の意図と、相手から見えることを並べる） |
| **re:pair** | 関係をどう直す？（事実／責任／影響／修復／再発防止） |
| **re:cord** | 自分の記録（結果のスナップショット保存と見返し、前回との比較） |
| **re:share** | 結果をシェアする（共有カードの画像生成・保存・印刷/PDF） |

## 診断のしくみ

- **全60問**（状況判断36問 / 6段階の自己評価16問 / 理解-実行8問）を、12問×5チャプターで構成
- **8軸**で結果を出します
  - 向き合うための反応：真実開示 / 責任受容 / 相手への影響理解 / 修復行動 / 再発防止
  - 守りに入るときの反応：自己正当化 / 防衛的反発 / 回避・隠蔽（良し悪しではなく「出やすさ」）
- **理解―実行ギャップ**：適切だと思う対応と、実際に取りそうな行動の差
- **プレッシャー比較**：同じ心理テーマで失うものの大きさだけが違う11組のペア設問で比較
- **危険トリガー**：本人の平均的な傾向（ベースライン）との差分で判定し、条件を満たさなければ順位を出しません
- **キャラクター11種**：初動／立て直し／サブ傾向を、単一の軸ではなく複数軸の重み付き組み合わせから決定

### 回答バイアス対策

- 選択肢の表示順を診断ごとにランダム化（順序は保存され、戻る・再開しても同じ並び）。採点は表示位置ではなく元データを参照します
- 望ましい選択肢にも現実的なコストを、そうでない選択肢にも本人なりの理由を持たせています
- 似た設問どうしに加えて、「普段の自分（自己評価）」と「場面での選択」の食い違いも見ます
- 理想的な回答が多い場合は、断定せずその旨を添えて表示します

## プライバシー

回答・記録・メモは**外部に送信されません**。すべて開いた端末のブラウザ内（localStorage、キー `react_v3`）にのみ保存されます。
アプリ内の「もっと見る → 保存とデータの削除」から、記録・メモ・今日の1問・下書き・全データを個別に削除できます。

ブラウザのデータを消した場合や、別の端末・別のブラウザで開いた場合、記録は引き継がれません。

<br>

## 技術

- **単一の `index.html`**。外部ライブラリ、外部API、フォント配信、画像ホスティングへの依存はありません
- キャラクターはすべてインラインSVG
- 共有カードは Canvas で生成（保存は Web Share API →ダウンロード→画像長押し の順にフォールバック）
- ライト／ダークの両テーマ対応、`prefers-reduced-motion` 対応、390px 前後のスマートフォンを最優先
- 埋め込み表示（iframe・アプリ内ブラウザ）ではブラウザが確認ダイアログを無効化することがあるため、削除やリセットの確認は「もう一度押す」方式（6秒で自動的に元に戻る）、記録へのメモは画面内の入力欄、リンク共有の通知は画面内メッセージで完結します
- 共有カードとバックアップの保存は、埋め込み表示なら用意された保存機能を使い、使えないときは画像の長押し／本文コピーに案内します。ファイルを直接開いた場合は通常のダウンロードです
