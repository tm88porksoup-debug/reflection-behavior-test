re:act — そのときの自分を知る

間違えたとき。責められたとき。失うのが怖くなったとき。
人は、いつも同じ自分ではいられません。
re:actは「追い詰められたときに、自分の中でどんな反応が出やすいか」を知るための自己理解ツールです。

■ 機能の構成（re:シリーズ）
re:act    そのときの自分を知る（60問診断）
re:play   あの場面をもう一度考える（反応シミュレーター）
re:phrase 言葉を整理する（防衛的な言葉の言い換え）
re:mind   今の気持ちを確認する（焦り・怒り・怖さなどの確認と手順）
re:view   相手からはどう見える？（自分の意図と、相手から見えること）
re:pair   関係をどう直す？（事実／責任／影響／修復／再発防止）
re:cord   自分の記録（結果のスナップショット保存と見返し）
re:share  結果をシェアする（共有カード生成・画像保存・印刷）
今日の1問  1日ひとつの短い問い（全20問・診断のスコアには影響しません）

■ 使い方
index.html をブラウザで開くだけです。
サーバー・ログイン・インターネット接続は不要です（完全オフラインで動作します）。
スマートフォンで使う場合は、このファイルを端末に保存してブラウザで開いてください。

■ プライバシー
回答・診断の記録・「未来の自分へ」のメモ・re:pairの下書き・今日の1問の履歴・
価値観の選択は、外部に送信されません。
すべて開いた端末のブラウザ内（localStorage）にのみ保存されます。
削除は、トップ画面の「もっと見る → 保存とデータの削除」から行えます。
結果画面の一番下にも「保存されたデータを全部削除する」があります。

■ 注意書き
本診断は心理学研究の知見を参考にした自己理解ツールであり、
臨床心理検査・医学的診断・科学的に妥当性が検証済みの心理尺度ではありません。
将来の不倫・犯罪・裏切り等を予測するものではありません。

■ デザイン（re:act）
・ブランド名 re:act ／ メインコピー「そのときの自分を知る」
・くすみカラー（アイボリー / セージ / くすみピンク / ラベンダー / サンド）
・絵本風の柔らかいマスコット11種（すべてインラインSVG・外部画像なし）
・トップ、チャプター移行、結果前の短い間、結果、共有カードまで一貫した世界観
・ダークモードは黒ベースではなく暖かいダークブラウン
・iPhone(390px)片手操作前提。prefers-reduced-motion 対応

■ 収録内容
・60問（状況判断36問 / 6段階16問 / 理解-実行8問、12問×5チャプター）
・診断前の「今の自分」の状態選択（任意・スコアには影響しない）
・8軸プロフィール、理解-実行ギャップ、回答の一貫性、理想回答率の検知
・キャラクター11種（初動 / 立て直し / サブ）と図鑑
・あなたの中にある矛盾、危険トリガー、プレッシャー比較、責任と自己否定の分離
・IF→THEN 5ルール、共通ルール、問題のあとの5つの方向、過去-いま-これから
・結果から選ぶ「次に意識するひとつ」（トップ画面に表示されます）
・re:play / re:phrase / re:mind / re:view / re:pair / re:cord / re:share
・価値観コンパス、未来の自分へのメモ、前回との違い

──────────────────────────────
■ 診断設計の改訂（信頼性・バイアス対策）
──────────────────────────────
1. 選択肢の順番によるバイアス対策
   状況判断（SECTION 1）と理解-実行（SECTION 3）の選択肢は、
   診断セッションごとにランダムな順序で表示されます。
   順序は localStorage に保存されるため、戻る／再読み込み／再開をしても
   同じ診断中は同じ並びを維持します。
   SECTION 3 の「適切だと思う対応」と「実際に取りそうな対応」は同じ並びです。
   採点は表示位置ではなく、常に元の選択肢データを参照します。

2. 社会的望ましさへの対策
   36問すべての選択肢を書き直し、望ましい選択肢にも現実的なコスト
   （場が気まずくなる・未確定のまま出す等）を持たせ、
   そうでない選択肢にも本人にとって合理的な理由を持たせています。

3. 危険トリガー判定の変更
   絶対値の順位ではなく、本人の「普段の悪化傾向（ベースライン）」との差で判定します。
   場面スコア35以上かつベースラインより+10以上のものだけをトリガーとして表示し、
   該当がなければ順位を出さず、その旨を表示します。
   判定に使った設問数から「参考度（低/中/高）」も表示します。

4. 8軸の測定バランス調整
   防衛的反発（G）の測定機会が少なかったため、既存の設問を修正して
   G が自然に測定される選択肢を追加しました（設問総数は60問のまま）。

5. プレッシャー比較（旧HOT/COLD）の改善
   低圧・高圧の設問をばらばらに比較するのをやめ、
   「同じ心理テーマで、失うものの大きさだけが違う」11組のペア設問で比較します。
   名称も「失うものが小さい場面／大きい場面」に変更し、
   理解-実行ギャップとは別指標であることを結果画面で明示しています。

6. 理解-実行ギャップの改善
   適切さランクの差だけでなく、理想回答と実際回答の8軸上の距離も加味し、
   両者を半々で合成して0〜100にしています。結果画面で内訳も表示します。

7. 一貫性判定の改善
   似た意味の設問ペアに加えて、「普段の自分（自己評価）」と
   「場面での選択」の食い違いも検出し、高い／標準／やや揺れあり で表示します。

8. 断定表現の抑制
   特徴が弱い回答では「最大の弱点は○○」と書かず、
   「状況によって反応が変わりやすい」という結果として扱います。
   回避が低い人に「逃げやすい」と表示されないよう、文章分岐を追加しています。

■ 保存データについて（v3）
保存キーは react_v3 です。旧バージョン（self_reaction_check_v1 / v2）の
回答・途中経過・メモ・履歴は、初回起動時に自動で読み込まれ引き継がれます。
引き継ぎの時点では旧キーを消しません。
（「すべてのデータを削除する」を実行したときは、旧キーもまとめて削除されます）
診断結果は「スナップショット」として保存され、当時の結果画面をほぼそのまま再表示できます。
記録は最大20件で、古いものから消えていきます。
削除は「もっと見る → 保存とデータの削除」から、
診断の記録／未来の自分へのメモ／今日の1問の履歴／re:pairの下書き／いまの回答 を
個別に選べるほか、すべてまとめて削除することもできます。

■ 埋め込み表示（iframe・アプリ内ブラウザ）での動作について
ページを埋め込みで表示すると、ブラウザ側が確認ダイアログ（confirm / alert / prompt）を
無効化することがあります。そのままではボタンが無反応になるため、
・削除やリセットの確認は「もう一度押す」方式（6秒で自動的に元に戻ります）
・記録へのメモは画面内の入力欄
・リンク共有時の通知は画面内のメッセージ
としています。ファイルを直接開いた場合も同じ動作です。

共有カードの画像保存は、環境によってページからの直接ダウンロードが遮断されます。
その場合は、表示された画像を長押し（パソコンでは右クリック）して保存してください。

■ カスタマイズ
設問・選択肢・配点は index.html 内の S1 / S2 / S3 配列で管理しています。
S1_META（プレッシャー水準とトリガータグ）、PRESSURE_PAIRS（ペア設問）、
CHARS（キャラクターと判定係数）も同ファイル内で調整できます。
DAILY（今日の1問）、VIEWS（re:view）、SIM（re:play）、EXCUSES（re:phrase）、
REPAIR_STEPS（re:pair）も同様です。
スコアロジック（SCORING / ANALYSIS2 / TEXT / TEXT2）とUIロジックは分離しています。
